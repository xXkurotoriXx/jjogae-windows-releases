# Windows 화면과 기능

| 항목 | 동작 |
| --- | --- |
| 창 배치 | 최소 430 × 540, 좁은 창의 하단 메뉴와 넓은 창의 요약 카드 |
| 설정 | 창 너비에 맞춘 1–3열 카드와 저장 용량 구분 |
| 방송 기록 | 시간 수정, 과거 방송 추가, 분할 영상과 중복 합계 방지 |
| 썸네일 | 자동 보관, 직접 지정, 내보내기와 가져오기 |
| 계정 | 로그인 브라우저 재진입과 채팅 프로필 확인 |
| 멤버십 | 웹 연결·직접 입력과 홈·위젯의 가입 기간 표시 |
| 외부 브라우저 | 기본 브라우저·Edge·Chrome·Firefox 선택 |
| 알림 | Windows 알림 센터 전달과 상태 표시 |
| 시작프로그램 | 첫 실행 선택과 등록·해제, Windows의 사용 안 함 상태 표시 |
| 업데이트 | 파일 검증·교체·재실행, 실패 시 복원과 임시 파일 정리 |

화면은 WPF와 Windows DWM, 로그인 브라우저는 WebView2를 사용합니다. 테마와 배경 이미지는 설정에서 선택할 수 있습니다.
