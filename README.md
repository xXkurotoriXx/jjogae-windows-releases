# 쪼개 상황실 · Windows

아홀로 루파의 치지직·YouTube 채널과 네이버 카페 정보를 모아 보는 Windows 팬 앱입니다.

## 주요 기능

- 상황실: 방송 상태, 팔로워·구독자 수, 구독·멤버십 기간과 최신 영상 확인
- 사용 치즈: 월간 달력, 날짜별 사용 내역과 사용량 그래프
- 카페: 공지 확인, 읽음 관리와 기간을 지정한 과거 공지 불러오기
- 방송 기록: 월간 달력, 방송 시간 통계, 다시보기 목록과 썸네일 보관·가져오기·내보내기
- 위젯: 채널 지표와 이용 기간을 별도 창에서 확인
- Windows 알림: 방송 시작·종료, 새 영상·공지와 기념일 안내
- 설정: 새로고침 간격, 테마·배경 이미지, 시작프로그램과 기록 가져오기·내보내기
- 바로가기: 치지직, YouTube 아홀로 루파, YouTube 아홀로그, 네이버 카페

## 설치

Windows 10/11 · x64

1. [최신 릴리스](https://github.com/xXkurotoriXx/jjogae-windows-releases/releases/latest)에서 **JjogaeStatus.exe**를 받습니다.
2. 원하는 폴더에 두고 실행합니다.
3. 앱 설정에서 네이버·치지직과 YouTube에 로그인합니다. 로그인 화면에는 **Microsoft Edge WebView2 Runtime**이 필요합니다.

첫 실행에 Windows 시작프로그램 등록 여부를 선택할 수 있습니다.

창의 X 버튼은 앱을 최소화합니다. 종료하려면 설정의 **완전히 종료**를 누릅니다.

## 업데이트

**설정 → 앱 업데이트 → 업데이트 확인**을 누르면 새 버전을 내려받아 설치하고 앱을 다시 실행합니다. 기록과 설정은 유지됩니다.

**자동 업데이트**는 기본으로 켜져 있으며, 앱이 실행되는 동안 주 1회 확인하고 새 버전을 설치합니다. 설정에서 켜거나 끌 수 있습니다.
