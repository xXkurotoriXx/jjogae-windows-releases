# 쪼개 상황실 - Windows

치지직 스트리머 아홀로 루파의 방송 상태, 최신 영상, 카페 공지, 치즈 사용 내역과 방송 기록을 한곳에서 확인하는 비공식 팬 제작 Windows 앱입니다.

기록과 설정은 사용자의 PC에 저장되며, 필요한 정보는 앱이 치지직·네이버·YouTube에서 직접 조회합니다.

## 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 대상 | 아홀로 루파 채널을 시청하거나 후원하는 커뮤니티 사용자 |
| 실행 환경 | Windows 10/11 x64 |
| 계정 연결 | 앱 안에서 네이버·치지직과 YouTube 로그인 |
| 데이터 저장 | 사용자 PC의 앱 데이터 폴더 |
| 현재 버전 | 0.5.9 |

## 주요 기능

- 방송 상태, 팔로워·구독자 수와 구독·멤버십 기간 확인
- 최신 방송·영상·클립과 치지직·YouTube 아홀로 루파·YouTube 아홀로그·네이버 카페 바로가기
- 월간 달력, 루파 채널의 날짜별 치즈 사용 내역과 사용량 그래프
- 카페 공지 확인, 선택 읽음·모두 읽음 처리와 과거 공지 불러오기
- 방송 기록 달력, 방송 시간 통계와 다시보기 목록
- 방송 썸네일 보관·가져오기·내보내기
- 방송 시작·종료, 새 영상·카페 공지와 기념일 Windows 알림
- 별도 위젯, 라이트·다크 테마, 배경 이미지와 시작프로그램 설정

## 설치하는 방법

1. [최신 릴리스](https://github.com/xXkurotoriXx/jjogae-windows-releases/releases/latest)에서 **JjogaeStatus.exe**를 받습니다.
2. 다운로드 폴더 등 파일을 저장할 수 있는 폴더에 두고 실행합니다.
3. 치즈 내역과 개인 구독·멤버십 정보를 확인하려면 앱 설정에서 네이버·치지직과 YouTube에 로그인합니다. 방송 알림, 공개 카페 공지와 채널 구독자 수는 로그인 없이 확인할 수 있습니다.

로그인 화면에는 **Microsoft Edge WebView2 Runtime**이 필요합니다. 첫 실행에 Windows 시작프로그램 등록 여부를 선택할 수 있습니다.

설정에서 **X 버튼을 누르면 완전히 종료**를 켜면 X 버튼으로 앱을 종료합니다. 끄면 창이 최소화되고 알림 확인이 계속됩니다.

앱을 완전히 종료한 뒤 다시 실행하면 저장된 로그인 상태를 확인하고 치즈·방송 기록과 채널 정보를 동기화합니다. 인터넷 연결 문제로 확인하지 못하면 설정한 새로고침 주기에 다시 시도하며, 로그인 확인이 실패해도 저장된 기록은 유지됩니다.

## 앱 업데이트

홈 상단의 **업데이트 확인** 또는 **설정 → 앱 업데이트 → 업데이트 확인**을 누르면 최신 버전을 확인하고 필요한 업데이트를 설치한 뒤 앱을 다시 실행합니다. 기록과 설정은 유지됩니다.

앱을 다시 실행할 때와 실행되는 동안 주 1회 새 버전을 확인하고 홈 상단과 Windows 알림으로 알려줍니다. Windows 알림을 누르면 설정 화면이 열리며, **업데이트 확인**을 눌러 설치할 수 있습니다. 업데이트 알림은 기본으로 켜져 있습니다.

## 개인정보와 데이터 보관

- 기록과 설정은 이 PC의 앱 데이터 폴더에 보관합니다.
- 네이버·치지직에서 로그아웃하면 저장된 치즈 내역을 삭제합니다.
- 설정에서 기록을 JSON으로 내보내고 가져올 수 있으며, 썸네일은 별도로 내보낼 수 있습니다.
- 내보낸 파일에는 후원 메시지나 개인 기록이 포함될 수 있으니 공유 전에 내용을 확인해 주세요.
- **설정 → 데이터 → 모든 데이터 삭제**에서 최종 확인하면 기록·설정·로그인 캐시와 앱 데이터 폴더를 정리하고 종료합니다. 다음 실행 시 처음 상태로 시작합니다.

자세한 내용은 [개인정보처리방침](PRIVACY.md)과 [오픈소스 고지](THIRD_PARTY_NOTICES.md)를 확인해 주세요.
